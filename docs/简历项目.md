## 推荐使用（一页简历，5 条）

**高校场地资源预约系统（后端）**｜独立开发｜Java / Spring Boot / MyBatis-Plus / MySQL / Redis / JWT

- 实现独占型场地的查询、预约、取消与管理端维护；JWT 无状态鉴权，学生/教师预约、管理员维护场地与预约。
- 提交预约使用事务 + 用户/场地行锁（`FOR UPDATE`）防超约：先锁用户保证「未结束 ≤ 2」，再锁场地串行化冲突检查。
- 踩过 MySQL 默认可重复读的快照读问题（并发 20 路曾插入 12 条），改为读已提交并对配额/冲突查询加当前读，复测为 1 成功 / 19 冲突。
- Redis 仅 Cache Aside 缓存场地详情（TTL 1h，更新删缓存）；占用与提交不走缓存，Redis 宕机回源 DB，不影响预约正确性。
- 抽出时间对齐、区间相交、配额、取消窗口等领域规则并配单测；提供 Swagger / Postman 与 20 路并发验收脚本。

**技术栈可写一行：** Spring Boot 2.7、Java 17、Spring Security、jjwt、MyBatis-Plus、MySQL 8、Redis、SpringDoc

## 精简版（只留 3 条）

**高校场地资源预约系统**｜独立开发｜Spring Boot · MySQL · Redis · JWT

- 独立完成后端：登录鉴权、场地查询/占用、预约提交与取消、管理端场地与预约管理。
