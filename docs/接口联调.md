# 接口联调说明

Base URL：`http://127.0.0.1:8080`  
鉴权：`Authorization: Bearer <token>`（登录接口除外）  
时间：`Asia/Shanghai`；日期 `yyyy-MM-dd`；时刻 `HH:mm`  
统一响应：`{ "code": "OK", "message": "success", "data": ... }`

## 登录

`POST /api/auth/login`

```json
{ "username": "stu01", "password": "123456" }
```

账号：`admin` / `teacher01` / `stu01`，密码均为 `123456`。

## 用户端

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/venues` | 仅启用场地，可选 `type`、`campus` |
| GET | `/api/venues/{id}` | 详情（可走 Redis 缓存） |
| GET | `/api/venues/{id}/occupancy?date=` | 开放时间 + 当日 CONFIRMED 占用，只读 |
| POST | `/api/reservations` | 提交预约 |
| GET | `/api/reservations/me?filter=` | `UPCOMING` / `ONGOING` / `ENDED` / `CANCELLED` |
| POST | `/api/reservations/{id}/cancel` | 本人，须提前 2 小时 |

提交示例：

```json
{
  "venueId": 1,
  "date": "2026-09-10",
  "startTime": "10:00",
  "endTime": "11:00",
  "purpose": "组会"
}
```

占用接口只供画格子；**能否约上以提交接口为准**。

## 管理端（仅 ADMIN，学生调会 403）

| 方法 | 路径 |
|---|---|
| GET/POST | `/api/admin/venues` |
| PUT | `/api/admin/venues/{id}` 启停与信息 |
| GET | `/api/admin/reservations?venueId=&userId=&date=` |
| POST | `/api/admin/reservations/{id}/cancel` 开始前即可 |

无物理删除场地。停用后禁止新约，已有预约不自动取消。

## 常见错误码

| code | HTTP | 含义 |
|---|---|---|
| UNAUTHENTICATED | 401 | 未登录或 Token 无效 |
| FORBIDDEN | 403 | 已登录但无权限 |
| CONFLICT | 409 | 时段与他人相交 |
| DUPLICATE_RESERVATION | 409 | 本人同场同起止已有单 |
| QUOTA_EXCEEDED | 400 | 未结束预约已达 2 条 |
| VENUE_DISABLED | 400 | 场地已停用 |
| CANCEL_NOT_ALLOWED | 400 | 取消窗口外或已开始 |
| OUT_OF_OPEN_HOURS | 400 | 不在开放时间 |

完整用例见仓库根目录 Postman 集合。
